## Описание программы

**Book Tracer** - это GUI-приложение для управления списком прочитанных книг. Приложение позволяет добавлять книги , фильтровать их по жанру и количеству страниц, сохранять и загружать данные в формате JSON,  а также удалять отдельны записи или весь список целиком. 

### Возможности:

- Добавление книг с указанием названия, автора, жынра и количества страниц
- Фильтрация книг по жанру ( Роман. Фантастика. Детектив. и др) 
- Фильтрация по количеству страниц(>200, >300, >500)
- Сохранение данных в JSON-файла
- Удаление выбранной книги
- Очистка всего списка книг
- Валидация вводимых данных ( проверка пустых полей, числовое занчение страниц)

## Иструкция по запуску 

## Требования:
- Python 3.6 или выше 
- Установленная библиотека Tkinter (обычно идет в комплекте с Python)

### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проетка: 
       bash
    cd bookTracer

3. Запустите приложение:
       bash
   Python main.py


## Примеры  пользования

### Добавление книги:
1. Заполните все поля формы;
   - **Навзание книги:** "Мастер и маргарита"
   - **Автор:** "Михаил Булгаков"
   - **Жанр:** Выберите из списка ( например, "Роман")
   - **Количество страниц:** 480
2. Наждмите кнопку **"Добавить книгу"**
3. Книга появится в списке внизу окна 

### Фильтрация:
- **По жанру:** Выберите жанр из выпадающего списка в разделе "Фильтры"  и нажмите "Применить фильтр"
- **По страницам:** выберите критерии  ( ">200", ">300", ">500")   и нажмите "Примените фильтр"
- Можно комбинировать оба фильтра одновременно
